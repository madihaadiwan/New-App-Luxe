# Luxe By Madiha - Business Manager

A Streamlit app for a ready-to-wear clothing brand: new arrivals slideshow, price and profit calculator, stock tracker, order tracker, and Instagram caption maker. Includes a WhatsApp contact button.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy
Push these files to GitHub and deploy on share.streamlit.io with `app.py` as the main file. No API key needed.
